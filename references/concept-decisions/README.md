# Concept Decisions

本目录记录概念新增、重命名、拆分、合并和弃用的决策。

## File Naming

使用 `YYYY-MM-DD-<topic>.md`。

## Required Sections

每条 decision record 至少包含：

1. Context
2. Previous approach
3. Problem / failure modes
4. Alternatives considered
5. Decision
6. Rationale and tradeoffs
7. Scope / non-goals / open items
8. Compatibility notes
9. Validation
